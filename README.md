# Crochet Grid Designer

Turn a picture into a pixel-style crochet chart: pick the stitch (sc, hdc, dc, Tunisian, C2C),
size the grid, choose how many yarn colors, then edit the chart and follow the row-by-row pattern.

**Open the app:** https://applaudedadam-beep.github.io/crochet-grid-designer/

On iPhone or iPad, open the link in Safari and tap **Share → Add to Home Screen** to use it like an app
(it keeps working without an internet connection once it has been opened).

Everything runs in your browser — pictures and charts are never uploaded anywhere.
